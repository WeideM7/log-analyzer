# 三源日志时间对齐分析器

一个基于浏览器的单文件日志分析工具，用于同时载入并分析多个日志文件的时间关联。特别适合分析 VR 系统（如 PICO Connect）的多组件日志，快速定位"某时间段内各系统同时发生了什么"。

## 核心功能

- **三栏时间对齐** — 同时显示 3 个日志源，点击任意行自动跳转到各源时间上最接近的记录
- **自动时间解析** — 支持多种时间格式自动识别，无需手动指定
- **无日期对齐** — 纯时间日志自动对齐到有日期日志的同一天
- **时钟偏移校准** — 手动微调秒级偏移，校准不同设备/进程的时钟差
- **合并流视图** — 三源日志按时间交错排序，带彩色来源徽章
- **时间轴热区** — Canvas 绘制的日志密度分布图，点击/拖动快速跳转
- **AI 分析导出** — 一键复制当前时间窗的日志片段，供 AI 进行因果分析
- **PICO 日志一键载入** — 通过 File System Access API 直接从 PICO Connect 日志目录导入

## 支持的时间格式

| 格式 | 示例 |
|------|------|
| ISO 标准 | `2026-09-28 21:46:04.445` |
| 中文日期 | `2026年09月28日 21:46:04` |
| 英文月份 | `Sep-28-2026 21:46:04.445` |
| Unix 时间戳 | `1695930364000` (13位) / `1695930364` (10位) |
| 纯时间 | `21:46:04.445`（自动推断日期，跨午夜自动+1天） |

## 使用方法

### 1. 打开工具

直接用浏览器打开 `log-analyzer.html` 文件即可，**无需任何服务器或安装**。

> 注意：由于使用了 File System Access API，需要使用 Chrome 86+ 或 Edge 86+ 浏览器。

### 2. 载入日志

有三种方式载入日志：

**方式 A：手动选择文件**
- 点击每个栏位的"选择TXT"按钮，选择 `.txt` 或 `.log` 文件
- 支持拖拽文件到页面直接载入

**方式 B：PICO 日志一键载入**
- 点击"PICO日志"按钮
- 首次使用会提示"因权限问题需要手动选择 PICO Connect\\logs\\ps_server 目录"
- 在弹出的目录选择器中找到 PICO Connect 日志目录
- 浏览器会记住该目录，下次点击直接载入
- 自动匹配 `pico_connect.log`、`pico_connect_sdk.log`、`main.log` 三个文件

**方式 C：GitHub 样本测试**
- 仓库 `samples/` 目录下包含 3 个 PICO 日志样本文件
- 可下载后通过方式 A 载入测试

### 3. 分析日志

**时间对齐**
- 点击任意栏位的任意行，其他两栏自动跳转到时间上最接近的记录
- 每栏标题右侧显示当前选中行的时间，以及与其他源的时间差（Δ）

**时间轴导航**
- 顶部 Canvas 区域显示各日志的时间密度分布
- 白色竖线表示当前选中时间点
- 点击或拖动时间轴快速跳转

**搜索与过滤**
- 在搜索框输入关键字，日志中高亮显示匹配内容
- 勾选"仅匹配"可只显示包含关键字的行
- 使用 ↑ ↓ 按钮在匹配项之间跳转

**合并流视图**
- 点击"合并流"按钮，三源日志按时间顺序合并显示
- 每条记录带 A/B/C 彩色徽章标识来源

**时钟偏移校准**
- 每个栏位可设置"偏移s"（秒），用于校准不同设备/进程的时钟差
- 修改偏移后，该源的所有时间戳会相应平移

### 4. AI 分析导出

- 点击"AI分析导出"按钮，复制当前时间点前后 10 秒的日志片段到剪贴板
- 粘贴给 AI（如 ChatGPT/Claude）进行因果分析
- 也可在浏览器控制台手动调用：
  ```javascript
  window.logAnalyzer.context(timestamp, radiusSec);  // 导出指定时间窗
  window.logAnalyzer.stats();                         // 查看已载源统计
  window.logAnalyzer.seek(timestamp);                 // 跳转到指定时间
  window.logAnalyzer.search("keyword");               // 搜索关键字
  ```

## PICO Connect 日志路径

正式版 PC 端 PICO Connect 日志位置：

```
C:\Users\<用户>\AppData\Local\PICO Connect\logs\ps_server\  （用户级）
C:\ProgramData\PICO Connect\logs\ps_server\                   （系统级）
%TEMP%\PICO Connect\logs\ps_server                              （临时目录）
```

## 技术细节

- **零依赖**：纯 HTML/CSS/JS 单文件，无需构建工具
- **虚拟滚动**：仅渲染视口内行，轻松处理数十万行日志
- **编码自动检测**：优先 UTF-8，检测到乱码自动回退 GB18030
- **离线可用**：所有逻辑在浏览器本地运行，日志数据不会上传
